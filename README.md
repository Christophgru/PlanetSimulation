# PlanetSimulation

A C++20/OpenGL simulation engine for planetary systems with emphasis on numerical correctness and procedural rendering.

## Prerequisites

- **CMake** (3.16 or higher)
- **C++20 compatible compiler** (GCC 9+, Clang 7+, MSVC 2019+)
- **OpenGL development libraries**
- **GLEW** (OpenGL Extension Wrangler Library)
